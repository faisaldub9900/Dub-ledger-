DUB LEDGER 14.01 — INSTALLATION GUIDE (URDU)

یہ Debian 13 پر مبنی 64-bit Linux نظام ہے، Microsoft Windows نہیں۔
تنصیب سے پہلے اہم فائلوں کا الگ بیک اپ ضرور بنائیں۔

زبان اور کی بورڈ:
- English (United States)
- Locale: en_US.UTF-8
- Keyboard: US

ڈاؤنلوڈر:
- XDM (Xtreme Download Manager) عام فائلوں اور سپورٹڈ ویب ویڈیوز کے لیے شامل ہے۔
- Chrome، Edge یا Firefox میں XDM کی آفیشل براؤزر ایکسٹینشن الگ سے انسٹال/فعال کرنا پڑ سکتی ہے۔
- Video Downloader (Parabolic) ویڈیو/آڈیو لنک پیسٹ کرکے ڈاؤنلوڈ کرنے کے لیے شامل ہے۔
- ہر ویب سائٹ یا ہر ویڈیو ڈاؤنلوڈ نہیں ہو سکتی۔ XDM YouTube اور DRM-protected مواد کو سپورٹ نہیں کرتا۔
- صرف وہ مواد ڈاؤنلوڈ کریں جسے محفوظ کرنے کی آپ کو اجازت ہو۔

پارٹیشن کی حفاظت:
1. USB سے بوٹ کرکے Graphical Install منتخب کریں۔
2. Manual partitioning منتخب کریں۔ "Guided - use entire disk" ہرگز منتخب نہ کریں۔
3. Linux میں Windows کے C:, D:, E: یا R: ڈرائیو لیٹر نہیں ہوتے۔
4. صرف مطلوبہ پرانے Windows C: پارٹیشن کو / کے طور پر منتخب کریں اور صرف اسی کو format کریں۔
5. D:, E: یا R: کے ڈیٹا والے پارٹیشن حذف یا فارمیٹ نہ کریں۔
6. UEFI کمپیوٹر میں موجود EFI System Partition کو /boot/efi پر لگائیں، اسے format نہ کریں۔
7. آخری partition summary اچھی طرح دیکھیں۔ اگر کسی دوسرے ڈیٹا پارٹیشن کو format/delete دکھایا جائے تو تنصیب روک دیں۔

اہم: پرانے C: پارٹیشن کو format کرنے سے اس پر موجود Windows اور تمام فائلیں مٹ جائیں گی۔
اصل پارٹیشن لے آؤٹ اور انسٹالر کو اسی کمپیوٹر پر ٹیسٹ کیے بغیر D/E/R کے محفوظ رہنے کی ضمانت نہیں دی جا سکتی۔
